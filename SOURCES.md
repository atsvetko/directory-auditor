# Primary sources

Every check in the catalogue cites one or more of the sources below. Add to this list in the
same pull request that adds a check citing a new source. Vendor documentation of PingCastle or
Purple Knight is never a source (see docs/clean-room.md).

- Microsoft Learn — Active Directory, AD CS, Group Policy, DNS, Kerberos, LAPS documentation
- Microsoft Open Specifications — MS-ADTS, MS-GPOL, MS-DNSP, MS-CRTD, MS-SAMR, MS-PAC
- MITRE ATT&CK Enterprise — techniques and sub-techniques
- ANSSI — Recommandations de sécurité relatives à Active Directory (and the AD control points)
- DISA — Active Directory Domain and Forest STIGs
- SpecterOps — "Certified Pre-Owned" (AD CS ESC1–ESC8) and follow-up research (ESC9–ESC13)
- ADSecurity.org (Sean Metcalf) — attack and defence write-ups
- Kevin Robertson — ADIDNS research (Powermad)
- ФСТЭК России — Банк данных угроз безопасности информации (БДУ)
- CIS Benchmarks, NIST SP 800-53, ISO/IEC 27001:2022, PCI DSS 4.0, DORA; ГОСТ Р 57580.1,
  приказы ФСТЭК № 17, 21, 239 — for compliance mappings only
