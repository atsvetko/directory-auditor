What it is

A free security auditor for directory services and everything around them. It reads the directory the way an attacker would and reports misconfigurations and known-exploitable conditions in the directory core (ACLs, delegation, privileged groups, trusts), DNS (zone rights, insecure dynamic updates, wildcard records), Group Policy (GPO and SYSVOL rights, GPP passwords, scripts), PKI (AD CS templates and CAs, ESC1–13), Kerberos, credential management (LAPS, gMSA, Protected Users) and integrated applications (Exchange, SCCM, Entra Connect).

One engine, several directories: Active Directory and Samba AD DC first (which also covers РЕД АДМ and Альт Домен), then FreeIPA / ALD Pro and OpenLDAP, then Entra ID.

How it runs

Download→Run→Read
  • Double-click on Windows or ./dirauditor on Linux: a local web wizard detects the domain and your identity and offers Scan now.
  • Runs as your current logon over Kerberos; works against hardened DCs (LDAP signing, channel binding, LDAPS).
  • Console mode for jump hosts; flags for scheduled runs and CI; --demo shows a full report without any domain. Quick scan first, full scan one click later.

What you get

  • A 0–100 score overall and per area; top 5 paths to Tier 0; quick wins fixable in ten minutes.
  • Every finding with why it matters, how it is abused, the exact fix command (PowerShell, ldapmodify, samba-tool, ipa) and how to verify; fix --plan writes a dry-run script for the findings you select.
  • Self-contained HTML report in English or Russian, plus JSON and CSV; diff between runs; redaction for sharing outside the team; what was checked, passed and skipped, and why.

Status and open decisions

Concept stage. Open: engine language (Go vs .NET Native AOT), governance, Russian software-registry route, Astra Linux signing in v1. Wanted: pilot domains, contributors, reviewers.

Why it is safe to run on production

  • Read-only, provably. No write paths are compiled in; every release ships a test showing the binary contains no LDAP modify, SMB write or DNS update code — any reviewer can reproduce it.
  • No exploit code. Vulnerabilities are inferred from versions, flags and ACLs; nothing is attempted, relayed or sprayed; no account can be locked out.
  • Signed and reproducible. Authenticode with immediate SmartScreen reputation, cosign/minisign for Linux and macOS, Astra Linux ЗПС signature; reproducible builds, SBOM, SLSA provenance.
  • Transparent. Checks are readable, signed YAML packs; --dry-run prints which DCs and queries a run will touch — paste it into the change ticket.

Built for enterprise approval

Every release ships a CI-generated security review pack: threat model, network-interactions sheet, full query manifest, SBOM, provenance, scan results, SOC runbook with expected EDR alerts, personal-data inventory, read-only proof. Plus MSI / .deb / .rpm packages, a least-privilege audit-account script, and per-check mappings to CIS, NIST SP 800-53, ISO 27001, PCI DSS 4.0, DORA, ГОСТ Р 57580, ФСТЭК, БДУ.
